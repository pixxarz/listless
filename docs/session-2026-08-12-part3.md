# บันทึกการทำงาน — 12 สิงหาคม 2569 รอบ 3 (v1.6.0)

> บันทึกไว้ให้คนที่มาทำต่อรู้ว่าแต่ละอย่างแก้เพราะอะไร ไม่ใช่แค่แก้อะไร

รอบนี้เริ่มจากคำถามเดียว — "กราฟบวกกันแล้วมันเกินการ์ด" — แล้วสาวไปเจอบั๊กตระกูลเดียวกันอีก 5 ตัวที่ซ่อนอยู่ข้างหลัง

## 1. กราฟนับผิดหน่วย

**อาการ** การ์ดบอก **148 คน** แต่กราฟแยกระดับชั้นบวกกันได้ **737**

**สาเหตุ** การ์ดนับ "คนไม่ซ้ำ" กราฟนับ "แถวในชีต" ทั้งที่เขียนหน่วยว่า "คน" เหมือนกัน — เด็ก 1 คนที่ถูกรายงาน 5 วิชา ถูกนับ 5 ครั้งในกราฟ (737 ÷ 148 ≈ 5 พอดี ยืนยันสาเหตุ)

**แก้** ตั้งกติกานับคนไว้ที่เดียว (`stuKey` → `countStu`) แล้วบังคับให้ทุกกราฟเรียกตัวนี้ตัวเดียว

- แท่ง = คนไม่ซ้ำ · ชี้เมาส์เห็นทั้งสองเลข **"ม.3 : 41 คน (203 รายการ)"** ไม่เสียข้อมูลเดิม
- ถ้ายอดรวมแท่งเกินการ์ด (ชื่อเดียวโผล่ 2 ระดับชั้น) มีหมายเหตุใต้กราฟบอกเหตุผล **ดีกว่าปล่อยให้เลขสองตัวขัดกันเงียบ ๆ**
- กราฟช่วง % ก็เหมือนกัน + หมายเหตุว่า 1 คนอยู่ได้หลายช่วง เพราะแต่ละวิชามี % ไม่เท่ากัน (ซ้ำโดยธรรมชาติ ไม่ใช่บั๊ก)
- กลุ่มเสี่ยงเดิมเขียน "ดูทั้งหมด (N คน)" ทั้งที่ N คือจำนวนรายการ → แก้เป็น "รายการ"
- ตารางครู/วิชา ช่อง "จำนวนนักเรียน" เดิมนับรวมคำนำหน้า (เด็กหญิง/นางสาว คนเดียวกันกลายเป็น 2 คน) → ใช้กติกาเดียวกับการ์ด

**ทดสอบ** ยัดข้อมูล 737 แถวตามสัดส่วนจริง → การ์ด 148 · รวมทุกแท่ง **148 พอดี**

## 2. เด็กคนเดียวแตกเป็น 2 แถว ทั้งที่ทุกช่องเหมือนกันเป๊ะ

**อาการ** `ธนวิชญ์ อุณวงศ์ · ม.2/1 · เลขที่ 13 · ด.ช.` โผล่ 2 แถว (1 วิชา กับ 3 วิชา) ต่างกันตรงไหนก็มองไม่ออก

**สาเหตุจริง — ได้จากรหัสอักขระของข้อมูลจริง ไม่ใช่การเดา**

```
ครูคนที่ 1 พิมพ์   ธนธรณ์ มณีเลิศ     14 ตัวอักษร   (เว้นวรรค 1 ที)
ครูคนที่ 2 พิมพ์   ธนธรณ์  มณีเลิศ    15 ตัวอักษร   (เว้นวรรค 2 ที)   ← รหัส 32 ซ้อนกัน
```

🚨 **เดาผิดไป 1 รอบก่อนหน้านี้** — ฟันธงว่าเป็นช่องว่างท้ายช่อง "ชั้น/ห้อง" ปรากฏว่าห้องเหมือนกันเป๊ะ พอได้รหัสอักขระจริงมาดูจึงจบใน 1 นาที · **บทเรียนเดิมซ้ำอีกรอบ: ขอหลักฐานก่อนเดา**

**อีกตัวที่เจอระหว่างทาง** สระ/วรรณยุกต์ไทยพิมพ์สลับลำดับกันได้ `กี่` กับ `ก่ี` หน้าจอเหมือนกันเป๊ะ แต่คนละค่า และ **`normalize('NFC')` แก้ไม่ได้** (ทดสอบยืนยันแล้ว ยูนิโค้ดไม่จัดลำดับเครื่องหมายไทยให้)

**แก้** `visKey()` ใน `js/fixes.js` เป็นตัวจริงตัวเดียวของทั้งเว็บ (`report.js` เรียกผ่าน `FIXES.visKey` — **ห้ามเขียนสำเนา** ถ้าสองไฟล์ล้างคนละชุด การ์ดกับกราฟจะนับไม่ตรงกันทันที) ล้าง 4 อย่างก่อนเทียบ

1. เว้นวรรคซ้ำ / หัวท้าย
2. อักขระที่ไม่แสดงผล (zero-width, BOM, soft hyphen)
3. ช่องว่างพันธุ์แปลก (NBSP ฯลฯ)
4. **เรียงสระ/วรรณยุกต์ที่เกาะพยัญชนะตัวเดียวกัน** — ปลอดภัยเพราะไทยมีลำดับถูกแบบเดียว อีกลำดับคือพิมพ์ผิด

⚠️ **ใช้เทียบเท่านั้น ห้ามเอาผลไปแสดงหรือเขียนลงชีต**

**ทดสอบ** `โมยา`/`โมหา` และ `ถานิช`/`ถานิชย์` ยังถูกมองเป็นคนละคำ — ไม่ยุบเกินขอบเขต

## 3. แก้ที่ต้นทาง — ฟอร์มครูล้างให้ก่อนบันทึก

ข้อ 2 คือการตามเช็ดทีหลัง ตัวแก้เหตุอยู่ที่ฟอร์ม

`cleanText()` ใน `js/index.js` ครอบทุกช่องใน `collectData()` (ชื่อนักเรียน · ห้อง · ชื่อครู · ชื่อวิชา · รหัสวิชา · หมายเหตุ)

🚨 **ล้างเฉพาะสิ่งที่ลบแล้วหน้าตาไม่เปลี่ยน ห้ามแตะตัวสะกดของครูเด็ดขาด** และ**ไม่**จัดลำดับสระให้ (อันนั้นเก็บไว้เป็นการเทียบอย่างเดียว) — เป็นการแตะตัวหนังสือที่ครูพิมพ์จริง ต้องให้คนเคาะก่อน

ตั้งแต่ deploy ไป ปัญหานี้จะไม่เกิดใหม่ ที่แก้ในหน้ารายงานคือเก็บกวาดของเก่าที่ค้างในชีตแล้ว

**ไม่ต้อง deploy Apps Script** — เป็นไฟล์หน้าเว็บ Netlify ดีพลอยเอง

## 4. หน้าตรวจสอบข้อมูลมองไม่เห็นเคสพวกนี้เลย

**พิสูจน์แล้วด้วยการเอาฟังก์ชันจริงมารัน**

```
ค่าดิบต่างกันไหม        → ต่าง
หลังผ่าน rawName()      → เหมือนกัน   ← ยุบช่องว่างซ้ำทิ้งไปก่อนแล้ว
หลังผ่าน phonetic()     → เหมือนกัน   ← ตัดช่องว่างทิ้งหมด
```

พอเทียบกันแล้วเหมือนกัน **ไม่มีคู่ให้เสนอ = เงียบหายไปเลย**

**แก้ 2 อย่าง**

**ก. เพิ่ม `detectInvisible()`** จับกลุ่มด้วย `visKey` แล้วเทียบค่า**ดิบ**ข้างใน (ห้องไม่ต้องทำซ้ำ `detectRooms` จับด้วยค่าดิบอยู่แล้ว)

**ข. ผ่อนกฎนามสกุล** จาก "เหมือนกันเป๊ะ" เป็น "ต่างได้ไม่เกิน 2 ตัว" — เดิมทำให้เคสที่ครูพิมพ์**นามสกุล**ผิดไม่เคยถูกเสนอเลยสักครั้งตั้งแต่ทำระบบมา (`ธิวาธร ถานิช`/`ถานิชย์` · `วรัขยา โมยา`/`โมหา`) · พี่น้องยังกันอยู่ด้วยด่านชั้นเรียนกับด่านชื่อตัวซึ่งไม่ได้แตะ

**ค. `describeOdd()` เขียนบอกเป็นคำ** — `diffHTML()` ไฮไลต์สิ่งที่ไม่มีตัวตนบนจอไม่ได้ ไฮไลต์ช่องว่างไปก็ยังมองไม่เห็น การ์ดจึงต้องเขียนว่า **"เคาะเว้นวรรค 2 ที ติดกัน"** ตรง ๆ ไม่งั้นคนกดมั่ว

## 5. หลักการแสดงผลที่ตั้งใหม่ (มาจากคำติของผู้ใช้ตรง ๆ)

> "กรอบแดงแปลว่าอะไร เพื่อนเราจะรู้ไหม"

**กฎ: กรอบแดงตีเฉพาะช่องที่แสดงสองค่าให้เห็นอยู่แล้ว** (`36, 37` · `ด.ช., ด.ญ.`)
ช่องที่เนื้อในดูปกติทุกอย่าง **ห้ามตีกรอบ** — บอกด้วยป้ายข้อความแทน

**ทุกแถวที่ผิดปกติมีป้ายภาษาไทยเสมอ** อ่านได้โดยไม่ต้องเอาเมาส์ไปชี้ · `เลขที่ไม่ตรงกัน` · `คำนำหน้าไม่ตรงกัน` · `ชื่อซ้ำ 2 รายการ ต่างที่ห้อง` · `ชื่อในชีตไม่ตรงกัน (ตาดูเหมือนกัน)`

**อย่าเอาสองค่าที่ตาเห็นเหมือนกันมาต่อกัน** — เคยได้ `ธนธรณ์ มณีเลิศ / ธนธรณ์ มณีเลิศ` ซึ่งอ่านแล้วเหมือนเว็บพัง (`dispVar()` เช็คก่อนเสมอ)

**หัวป๊อปอัปเปลี่ยนหน่วยเป็น "รายชื่อ"** — 1 คนที่ถูกกรอกคนละห้อง = 2 รายชื่อ แต่ 1 คน ถ้าเขียน "คน" ทั้งคู่ เลขจะขัดกับการ์ดเอง

## 7. เข้าครั้งที่สองไม่ต้องรอ

**วัดมาแล้ว** งานฝั่งเบราว์เซอร์ **0.23 วินาที** · เวลารอหลังบ้าน **10-29 วินาที** — คอขวดไม่ได้อยู่ที่หน้าเว็บ

**ทำไมแต่ก่อนเร็ว** `doGet` อ่าน **2 แผ่นทุกครั้ง** (`readSheet()` + `readFixes()`) แผ่นรายงานก็โตขึ้นเรื่อย ๆ

**ข้อจำกัดที่ต้องยอมรับ:** Apps Script เป็นของเพื่อนเจ้าของโปรเจกต์ **แก้จาก repo นี้ไม่ได้** — ทางเดียวคือทำฝั่งเบราว์เซอร์

**วิธี** จำข้อมูลรอบล่าสุดไว้ในเครื่อง → กรอกรหัสแล้วขึ้นจอทันที → คำขอจริงวิ่งอยู่ข้างหลัง → มาถึงแล้วสลับให้

**ตัวกันที่ต้องมี ห้ามถอด**

| ตัวกัน | เหตุผล |
|---|---|
| เก็บ **ลายนิ้วมือ SHA-256** ของรหัส ไม่ใช่ตัวรหัส | รหัสผิด = ไม่เห็นอะไร + ล้างทิ้ง |
| หมดอายุ 12 ชั่วโมง | ข้อมูลนักเรียนไม่ควรค้างในเครื่องข้ามวัน |
| "ออกจากระบบ" ล้างทันที | **ปิดเบราว์เซอร์เฉย ๆ ไม่ลบให้** นี่คือทางเดียวที่ผู้ใช้สั่งลบเองได้ |
| ไม่มี `crypto.subtle` = ไม่จำเลย | ปลอดภัยไว้ก่อน ดีกว่าใช้กุญแจอ่อน ๆ |
| แถบบอกสถานะ **บังคับมี** | ข้อมูลเก่าที่ไม่บอกว่าเก่า แย่กว่าหน้าเว็บที่ช้า |
| เน็ตล้มตอนโชว์ของเก่าอยู่ = **ห้ามเด้งกลับหน้ารหัสผ่าน** | ตอน Apps Script ตอบ 404 อันนี้คือสิ่งเดียวที่ยังใช้งานได้ |

`initApp()` มี `appReady` กันผูกปุ่มซ้ำ เพราะตอนนี้ถูกเรียก 2 รอบต่อการล็อกอิน 1 ครั้ง

**ทดสอบ 5 ขั้น ผ่านหมด** เก็บได้ 0.21 MB · รหัสถูกคืนข้อมูลใน 1 มิลลิวินาที · รหัสผิดไม่ได้อะไร · เก่า 13 ชั่วโมงลบทิ้งเอง · กดออกจากระบบล้างเกลี้ยง · หารหัสผ่านในไฟล์ที่เก็บ **ไม่มี**

## ทดสอบแค่ไหน

ทุกข้อข้างบนทดสอบด้วยการยัดข้อมูลจำลองเข้าไปในหน้าเว็บจริงแล้วอ่านผลจาก DOM จริง **ไม่ได้เทสผ่านหลังบ้าน** เพราะเครื่องที่พัฒนาไม่มีรหัสผ่าน

⚠️ **ยังไม่ได้ทดสอบกับข้อมูลจริงทั้งชุดบนเว็บจริง** — ขึ้นแล้วต้องดู
1. ยอดรวมแท่งกราฟ = ตัวเลขบนการ์ด
2. เข้ารอบสองขึ้นทันทีจริงไหม แถบสถานะขึ้นถูกไหม
3. หน้าตรวจสอบข้อมูลมีรายการใหม่โผล่มากี่อัน สมเหตุสมผลไหม
4. CSV กับเอกสารปริ้นยังถูกต้อง
