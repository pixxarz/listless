# 📋 ระบบรายงานนักเรียนเวลาเรียนไม่ถึงร้อยละ 70

ระบบสำหรับ **โรงเรียนชานุมานวิทยาคม** ให้ครูรายงานรายชื่อนักเรียนที่มีเวลาเรียนไม่ถึงร้อยละ 70 บันทึกลง Google ชีต แล้วพิมพ์เป็นเอกสารราชการ A4 ได้ พร้อมหน้าแดชบอร์ดสรุปข้อมูลทั้งหมด

เว็บล้วน (HTML/CSS/JavaScript) ไม่ต้องติดตั้งอะไร · หลังบ้านใช้ Google Apps Script + Google ชีต · โฮสต์บน Netlify

---

## ✨ ความสามารถ

### หน้ากรอกฟอร์ม — `index.html` (สำหรับครู)
- กรอกข้อมูลรายวิชา + รายชื่อนักเรียนที่เวลาเรียนไม่ถึงเกณฑ์ (คำนวณคาบขาด + ร้อยละให้อัตโนมัติ)
- **วันที่กรอกใส่ให้อัตโนมัติเป็นวันปัจจุบัน** เลือกเป็น วัน / เดือน / ปี พ.ศ. กดเปลี่ยนเองได้ และมีปุ่ม "วันนี้" กดกลับมาวันปัจจุบัน
- **เก็บร่างอัตโนมัติในเครื่อง** — กรอกค้างไว้แล้วเผลอรีเฟรช ปิดแท็บ ไฟดับ หรือสลับแอปบนมือถือ ข้อมูลไม่หาย พอเปิดหน้ามาใหม่ระบบจะถามว่าจะดึงกลับมาหรือเริ่มใบใหม่ (เก็บในเครื่องครูเองเท่านั้น ไม่ส่งขึ้นชีต และล้างทิ้งอัตโนมัติเมื่อบันทึกสำเร็จ)
- **ล้างช่องว่างเกินให้ก่อนบันทึก** (v1.6.0) — ครูเคาะเว้นวรรค 2 ที หรือก๊อปชื่อจากไฟล์อื่นมาแล้วติดอักขระที่มองไม่เห็นมาด้วย ทำให้เด็กคนเดียวถูกนับเป็น 2 คนในหน้ารายงาน · ระบบล้างให้เงียบๆ ก่อนส่งขึ้นชีต **ล้างเฉพาะสิ่งที่ลบแล้วหน้าตาไม่เปลี่ยน ไม่แตะตัวสะกดของครู**
- เตือนทันทีเมื่อกรอกเลขที่ซ้ำ และกันบันทึกถ้านักเรียนเวลาเรียนถึงร้อยละ 70 (ไม่เข้าเกณฑ์)
- บันทึก 2 ขั้น (ตรวจทาน → ยืนยัน) กันบันทึกพลาด
- พิมพ์เอกสารราชการ A4 (ปุ่มเดียว "พิมพ์ / บันทึก PDF")
- ใช้ได้ทั้งคอมและมือถือ

### หน้าแดชบอร์ดรายงาน — `report.html` (สำหรับผู้ดูแล)
- เข้าด้วยรหัสผ่าน (ตรวจที่ฝั่งเซิร์ฟเวอร์)
- การ์ดสรุปตัวเลข (KPI) + การ์ดเจาะลึก 4 แบบ: รายชื่อนักเรียน / ใบรายงาน / ครู / รายวิชา
- **ตรวจสอบข้อมูลที่กรอกผิด** (ปุ่ม 🔍 ตรวจสอบข้อมูล) — มี 2 โหมด
  - **ระบบตรวจพบ** — หาให้เองว่ามีชื่อนักเรียน ชื่อครู ห้องเรียน หรือรหัสวิชาที่น่าจะกรอกผิดตรงไหน แล้วเสนอให้คนกดยืนยัน เลือกค่าที่ถูก หรือพิมพ์ค่าที่ถูกเองก็ได้
  - **แก้เอง** — ค้นหาจากรายชื่อทั้งหมดแล้วแก้ได้เลย สำหรับกรณีที่ระบบหาไม่เจอ (ชื่อสะกดต่างกันมาก หรือกรอกผิดในใบเดียวจนไม่มีอะไรให้เทียบ) · ติ๊กหลายอันเพื่อรวมเป็นคนเดียว ติ๊กอันเดียวเพื่อแก้ชื่อหรือห้องของคนนั้น
  - แก้แล้วมีผลกับทุกส่วนของหน้ารายงาน (การ์ด กราฟ ตาราง CSV) แต่ **ไม่ยุบใบรายงาน** — ไปแก้ให้ถูกทุกใบที่เด็กคนนั้นถูกรายงาน · ยกเลิกได้ตลอด · ข้อมูลต้นฉบับในชีตและเอกสารที่ปริ้นไปแล้วไม่ถูกแตะ
  - **ผลการตรวจถูกเก็บไว้ในชีต** (แผ่น `แก้ข้อมูล`) ทุกคนที่เปิดหน้ารายงานจึงเห็นตรงกัน ไม่ต้องมากดซ้ำทีละเครื่อง และไม่หายแม้ล้างเบราว์เซอร์ · ระบบบอกสถานะทุกครั้งว่าบันทึกลงชีตแล้วหรือยัง ถ้าส่งไม่สำเร็จจะเก็บไว้ให้กดส่งใหม่ ไม่หายไปเฉยๆ
  - **ยืนยันแล้วแก้ลงแผ่น `รายงาน` จริง** ชีตที่เอาไปทำงานต่อจึงถูกต้องตามไปด้วย ไม่ใช่ถูกแค่บนหน้าเว็บ
    🚨 แก้เฉพาะ**ข้อความในช่อง**เท่านั้น **ไม่ลบแถว ไม่เพิ่มแถว ไม่สลับลำดับ** และแตะได้แค่ 6 ช่อง (ชื่อครู · คำนำหน้าครู · รหัสวิชา · ชื่อรายวิชา · ชื่อนักเรียน · ชั้น/ห้อง) ตัวเลขคาบเรียนกับรหัสใบไม่มีทางถูกแตะ
    ทุกปุ่มที่เปลี่ยนข้อมูล **มีกล่องยืนยันเสมอ** บอกว่าจะทับอะไร เป็นอะไร กี่ช่อง กี่แถว
    ค่าเดิมถูกจดไว้ในแผ่น `ค่าเดิม` (คนละแผ่น ไม่ไปเพิ่มคอลัมน์ในแผ่นรายงาน) จึง **กดย้อนกลับได้** ที่แท็บ **แก้ไปแล้ว**
  - **จับตัวอักษรที่มองไม่เห็นได้ด้วย** (v1.6.0) — ครูเคาะเว้นวรรคเกิน หรือก๊อปชื่อมาจากไฟล์อื่นแล้วติดอักขระซ่อนมา ทำให้เด็กคนเดียวถูกนับเป็น 2 คนทั้งที่หน้าจอดูเหมือนกันเป๊ะ · การ์ดจะเขียนบอกเป็นคำว่าต่างตรงไหน เช่น "เคาะเว้นวรรค 2 ที ติดกัน" เพราะการไฮไลต์ใช้กับสิ่งที่มองไม่เห็นไม่ได้
- **การ์ดกับกราฟนับเป็น "คน" ตรงกันทั้งหน้า** (v1.6.0) — แท่งกราฟนับคนไม่ซ้ำ ไม่ใช่นับแถว (เด็ก 1 คนถูกรายงาน 5 วิชา = 1 คน ไม่ใช่ 5) · ชี้เมาส์ที่แท่งเห็นทั้งสองเลข "41 คน (203 รายการ)" · ถ้ายอดรวมไม่ตรงกับการ์ด มีหมายเหตุใต้กราฟบอกเหตุผล
- **ป๊อปอัปรายชื่อไฮไลต์แถวที่ข้อมูลขัดกัน** (v1.6.0) — ชื่อซ้ำคนละห้อง เลขที่ไม่ตรง คำนำหน้าไม่ตรง จะมีป้ายสีแดงเขียนบอกเป็นภาษาไทยว่าผิดยังไง อ่านได้โดยไม่ต้องเอาเมาส์ไปชี้
- **เข้าครั้งที่สองไม่ต้องรอ** (v1.6.0) — หลังบ้าน (Apps Script) ใช้เวลา 10-29 วินาทีต่อครั้งและแก้ที่ฝั่งนั้นไม่ได้ เว็บจึงจำข้อมูลรอบล่าสุดไว้ในเครื่องแล้วขึ้นจอทันที พร้อมแถบบอกว่ากำลังโหลดของล่าสุดอยู่ · เก็บแค่ "ลายนิ้วมือ" ของรหัสผ่าน ไม่ได้เก็บตัวรหัส · หมดอายุเองใน 12 ชั่วโมง · กดออกจากระบบหรือกรอกรหัสผิดล้างทันที · ถ้าหลังบ้านล่มก็ยังดูข้อมูลได้
- ตารางหลักค้นหา-กรอง-เรียงได้ (เรียงซ้อนหลายชั้น + ตรึงคอลัม)
- ดาวน์โหลด CSV
- พิมพ์เอกสารได้ 2 แบบ:
  - **ใบรายงานครูเดี่ยว** (แยกตามครู/วิชา)
  - **บัญชีรายชื่อรวม** นักเรียนเวลาเรียนไม่ถึงร้อยละ 70 ทุกวิชา จัดกลุ่มตามระดับชั้น
- เช็ครายงานใหม่อัตโนมัติแบบเรียลไทม์

## 🚀 การใช้งาน

**ครู (กรอกข้อมูล):** เปิดหน้าฟอร์ม → กรอกข้อมูลวิชา + รายชื่อนักเรียน → กดบันทึก (ตรวจทาน → ยืนยัน) → กดพิมพ์เพื่อได้เอกสาร A4

**ผู้ดูแล (ดูรายงาน):** เปิดหน้ารายงาน → ใส่รหัสผ่าน → ดู/กรอง/พิมพ์/ดาวน์โหลดข้อมูล

## ⚙️ การติดตั้ง / Deploy

### หน้าเว็บ (Netlify)
ผูกกับ GitHub repo — ทุกครั้งที่ push ขึ้น branch `main` Netlify จะ deploy อัตโนมัติ ไม่ต้องตั้งค่าเพิ่ม

### หลังบ้าน (Google Apps Script)
1. เปิดโปรเจกต์ Apps Script ที่ผูกกับ Google ชีต → วางโค้ดจาก `Code.gs`
2. แก้ไขโค้ดแล้วต้อง **Deploy เวอร์ชันใหม่** ทุกครั้ง (Manage deployments → ดินสอ → Version: New version) — ลิงก์ (`SHEET_URL`) จะไม่เปลี่ยน
   🚨 **กด Run ในหน้า Apps Script ไม่นับเป็นการ deploy** เว็บจะยังคุยกับเวอร์ชันเดิมอยู่ นี่เป็นสาเหตุที่พบบ่อยที่สุดเวลาแก้โค้ดแล้วเว็บไม่เปลี่ยนตาม
3. ข้อมูลถูกเก็บใน 3 แผ่น (สร้างหัวตารางให้อัตโนมัติถ้ายังไม่มี)
   - **"รายงาน"** — ใบรายงานที่ครูกรอก (22 คอลัมน์ ระบบไม่เพิ่มคอลัมน์ให้เลย)
   - **"แก้ข้อมูล"** — ผลการตรวจสอบข้อมูลที่คนกดยืนยันแล้ว
   - **"ค่าเดิม"** — ค่าก่อนถูกแก้ ไว้กดย้อนกลับ (ดู `docs/spec-code-gs-fixes.md`)

### ตั้งรหัสผ่านหน้ารายงาน
แนะนำให้ตั้งแบบปลอดภัยผ่าน Apps Script:
Project Settings (รูปเฟือง) → Script Properties → Add → ตั้งชื่อ `REPORT_PASSWORD` แล้วใส่รหัสที่ต้องการ
(ถ้าไม่ตั้ง จะใช้ค่าเริ่มต้นในโค้ด ซึ่งควรเปลี่ยนก่อนใช้งานจริง)

## 📝 หมายเหตุ
- **เลขเวอร์ชัน + วันเผยแพร่** แสดงอยู่ท้ายหน้าฟอร์ม และมุมซ้ายล่างของหน้ารายงาน (เห็นได้ตั้งแต่หน้าใส่รหัสผ่าน ไม่ต้องล็อกอิน) ใช้ตรวจว่าเว็บจริงอัปเดตเป็นตัวล่าสุดแล้วหรือยัง — เปิดเว็บแล้วกด Ctrl+Shift+R ก่อนดูทุกครั้ง
- **เรื่องปีในวันที่ (พ.ศ. / ค.ศ.)** — ข้อมูลในชีตเก็บวันที่เป็น ค.ศ. แล้วเว็บแปลงเป็น พ.ศ. ตอนแสดงผลเสมอ · ก่อนหน้านี้ช่องปฏิทินของเบราว์เซอร์บนเครื่องที่ตั้งปฏิทินแบบพุทธศักราชส่งค่าออกมาเป็น พ.ศ. แล้วโดนบวก 543 ซ้ำ กลายเป็นปี 3112 · แก้แล้วโดยเลิกใช้ช่องปฏิทินของเบราว์เซอร์ และมีตัวแปลงดักไว้ทั้งฝั่งกรอกและฝั่งรายงาน ข้อมูลเก่าที่ยังเก็บเป็น พ.ศ. อยู่ในชีต (34 แถว) จึงแสดงผลถูกต้องแล้ว
- **ระบบตรวจวันที่ให้อัตโนมัติ** — ถ้าวันที่ในใบรายงานห่างจากเวลาที่บันทึกเข้าระบบจริงเกิน 1 ปี (เช่น นาฬิกาในเครื่องครูตั้งผิด หรือเลือกปีผิด) ระบบจะแก้ให้ตรงกับเวลาจริง แล้วติดสัญลักษณ์ ⚠ ไว้ท้ายวันที่ในหน้ารายงาน ชี้ที่สัญลักษณ์จะเห็นว่าต้นทางเขียนมาว่าอะไร
- เกณฑ์เวลาเรียนกำหนดที่ตัวแปร `THRESHOLD` (ค่าปัจจุบัน 70)
- การบันทึกกันข้อมูลซ้ำ/หายด้วยรหัสประจำใบ (`submission_id`) + ระบบล็อกกันบันทึกชนกัน + ยืนยันว่าข้อมูลเข้าชีตจริง
- วันที่ในชีตเป็นเวลาสากล (UTC) เว็บปรับเป็นเวลาไทย (+7) ก่อนแสดงเสมอ
- การ์ด "รายชื่อนักเรียนทั้งหมด" วาดเฉพาะแถวที่เห็นบนจอ (virtual scroll) และสร้างตารางวิชาย่อยเมื่อกดขยายเท่านั้น (lazy) เพื่อให้ป๊อปอัปเบา รองรับข้อมูลจำนวนมาก
- หากเปิดบนคอมบางเครื่องแล้วป๊อปอัปค้างชั่วครู่ตอนเปิด (เจอเฉพาะ Chrome/Edge บนคอมที่การ์ดจอ/ไดรเวอร์มีปัญหา ส่วน Firefox/Opera ปกติ) เป็นปัญหาที่เบราว์เซอร์/ไดรเวอร์ของเครื่องนั้น ไม่ใช่ตัวเว็บ — แก้ด้วยการอัปเดต Windows + ไดรเวอร์การ์ดจอ หรือใช้ Firefox
